# 路线图

## v0.1（当前）

- [x] 会话级数据流判定（打标 + 污点传播 + 编码变体）
- [x] 五道确定性守卫，全部可解释、可单独开关
- [x] 三态裁决 + 人工复核 + 监控模式
- [x] HMAC 防篡改审计链 + 独立尾锚 + 取证导出
- [x] 技能言行体检与合约生成
- [x] HTTP API、工作台、SDK、MCP/OpenClaw 适配
- [x] 17 个红队场景 + 55 条良性语料 + 98 个测试

## v0.2 稳定性与集成

- [ ] 官方 Python 包发布（PyPI）与 Docker 镜像（GHCR）
- [ ] 更多框架适配：LangChain、AutoGen、OpenAI Agents SDK、Claude MCP 示例
- [ ] 策略热加载 + 灰度（按工具/会话比例分流到 monitor）
- [ ] 审计链路对接外部不可变存储（S3 Object Lock / 只读介质）
- [ ] 告警通道：邮件、飞书/Lark、企业微信、Webhook
- [ ] 分级复核工作台（按风险/业务线分派、SLA 计时）

## v0.3 检测能力

- [ ] 语义污点：同义改写、分片重排的近似匹配
- [ ] 工具调用序列的异常模式基线（每会话/每 agent 的行为画像）
- [ ] 跨会话/跨主机数据流关联（同一蜜标在多个会话出现）
- [ ] 规则自动挖掘：从高置信审计记录生成候选正则，人工确认后入库
- [ ] 技能体检扩展到 Java/Go/Ruby，并支持 SBOM 关联

## v0.4 企业化

- [ ] 多租户与 RBAC（租户隔离、只读审计员角色）
- [ ] 策略即代码：版本化、diff 预览、回滚
- [ ] 审计报表：周期导出、合规映射（等保/ISO 27001 条款对照）
- [ ] 高可用：无状态裁决 + 共享审计存储，或双写仲裁

## 长期

- [ ] 标准化：把「工具调用合约」提交为社区规范（类似 OpenAPI for tools）
- [ ] 与 MCP 官方生态集成，提供「安全检查中间件」参考实现
- [ ] 公开评测基准：多轮工具调用攻击数据集 + 统一指标

欢迎在 issue 里认领条目，或在 roadmap 讨论区提出新方向。

# 威胁模型

## 1. 资产

| 资产 | 说明 |
| --- | --- |
| 主机与数据 | 被智能体操作的文件、数据库、业务系统 |
| 凭据 | `~/.ssh`、`~/.aws`、`.env`、环境变量、令牌 |
| 审计证据 | 裁决记录、数据流边、人工复核结论 |
| 审计链信任根 | HMAC 密钥、独立尾锚 |
| 智能体上下文 | 会话内的返回值与记忆 |

## 2. 对手

1. **外部内容投毒者**：在文档、网页、邮件、Issue 里埋提示注入，诱导智能体执行危险动作。
2. **恶意技能作者**：Skill 市场里的「言行不一」样本——文档说得人畜无害，代码偷偷联网、执行、读凭据。
3. **被劫持的智能体**：模型被越狱或目标被篡改，主动尝试外泄与持久化。
4. **内部越权使用者**：有主机权限但不应读取某些数据/不应改动审计的运维或攻击者。
5. **供应链攻击者**：下载脚本后立即执行、投毒依赖。

## 3. 信任边界

```
┌───────────────────────────┐         ┌──────────────────────────┐
│ 不可信                    │         │ 可信（本系统）            │
│ · 工具返回值/外部文档      │  ───▶   │ · 策略与合约文件          │
│ · 模型输出（含 Watcher）   │         │ · HMAC 密钥与尾锚         │
│ · 技能包代码（静态分析前） │         │ · 审计库                  │
└───────────────────────────┘         └──────────────────────────┘
```

- **模型输出不可信**：Watcher 的结论只能收紧，不能放开；它调用的工具是只读白名单。
- **工具返回值不可信**：入库即打标，含注入指令即隔离。
- **技能代码不可信**：只做静态分析，不执行；不一致即降级信任。
- **审计链自身可信**：依赖密钥保密与尾锚独立存放。

## 4. 攻击面与对应控制

| 攻击类别 | 典型形态 | 控制点 |
| --- | --- | --- |
| 凭据外泄链 | 读凭据 → 编码 → 外发 | 数据流守卫（`DF-EXFIL`）+ 蜜标（`CANARY`） |
| 提示注入落地 | 文档里写「忽略之前指令」「免审批」 | 规则（`INJ-*`）+ 结果侧隔离（`DF-QUAR`） |
| 隐写指令 | Unicode 标签字符、零宽字符、base64 载荷 | 隐写扫描（`STEGO-*`） |
| 持久化后门 | 改 `.bashrc`、写 cron、`nohup` | 合约（`CT-SCRIPT`）+ 规则（`SHELL-PERSIST/NOHUP`） |
| 破坏性操作 | `rm -rf`、`dd`、`mkfs` | 规则（`SHELL-RM-RF`、`SHELL-DISK`） |
| 越权读写 | 读 `~/.ssh`、写 `/etc` | 合约路径黑/白名单（`CT-PATH-*`） |
| 出网外发 | POST 到非白名单主机、访问元数据接口 | 合约网络白名单（`CT-NET-*`）、`NET-METADATA` |
| 写文件再执行 | `echo ... > x.sh && bash x.sh` | 合约脚本可信目录（`CT-SCRIPT-002/004`） |
| 技能言行不一 | 声明只读，实测联网 | 静态体检 + 技能合约（`CT-SKILL-*`） |
| 篡改审计 | 改记录、删尾、清库 | HMAC 链 + 独立尾锚 |
| 资源耗尽 | 批量参数、超高频调用 | 合约限额（`CT-LIMIT-*`） |

## 5. 不在防护范围

- **内核级逃逸**：智能体若已获得 root 并绕过本系统的旁路接入，本系统不在其路径上。
- **完全合法的数据搬运**：用户明确授权、且在白名单内的数据流动，按设计放行。
- **模型内部对齐问题**：本系统不修改模型权重，只约束其外显动作。
- **审计链信任根被完全攻陷**：拿到密钥 + 库 + 尾锚即可重写历史（见 residual risk）。
- **侧信道**：时序、功耗、缓存等侧信道不在范围内。

## 6. 残余风险与缓解

| 残余风险 | 缓解 |
| --- | --- |
| 语义改写绕过污点匹配 | 叠加编码变体检测、词元重叠、规则与合约多层；灰度期开启监控模式观察 |
| `rm -rf`/`sudo` 等保守规则误伤 | 监控模式灰度、按业务线覆盖策略、人工复核放行 |
| 语义研判把内容发给第三方模型 | 默认关闭（`provider = "none"`）；开启时脱敏 + 截断，可指向私有部署 |
| HMAC 密钥与尾锚同机存放 | 生产把尾锚写到独立存储/KMS 或只读介质；定期 `audit export` 异地留存 |
| 静态分析漏检混淆代码 | 结合运行时合约（`conditional` 只允许声明能力）+ 人工上架审核 |
| 审计库磁盘写满导致拒绝服务 | 失败即拒绝而非失败即放行；监控磁盘与链长，配合归档 |

## 7. 部署假设

1. 本系统与被监督智能体在同一主机或同一受控网络内，能拦截其工具调用入口；
2. 策略与合约文件由管理员维护，智能体与其内容来源无权修改；
3. 审计库所在目录仅本系统账号可写；
4. 系统时间大致正确（时间戳参与审计记录，但不参与签名）。
